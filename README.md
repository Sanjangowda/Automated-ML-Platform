Automated Machine Learning Platform (AutomL)
Welcome to the repository, this project helps user to build and train quality ML models without even writing a single line of code.


<img width="1920" height="1200" alt="Screenshot (63)" src="https://github.com/user-attachments/assets/01f2cc94-f737-4397-8136-68bc549403ba" />

In a home page you will see a button to upload dataset from your local device (supported dayasets file formats are: xls, spreadsheet, Json) 



<img width="1920" height="1200" alt="Screenshot (64)" src="https://github.com/user-attachments/assets/2ae761b1-cef4-4389-96e6-00561a38ecee" />
After uploading the dataset you can do EDA (Exploratory Data Analysis) in first tab, in second tab you can choose the model optimization metrics and select ML model to train on the selected dataset.



<img width="1920" height="1200" alt="Screenshot (68)" src="https://github.com/user-attachments/assets/eef9624b-1d92-4228-89e8-915c89d9f6d0" />
Finally you can download the trained model as .pkl format and can be deployed anywhere.

To run this on your local system install the following dependencies:
streamlit
scikit-learn
pandas
chardet
csv
os
xgboost
pickle
